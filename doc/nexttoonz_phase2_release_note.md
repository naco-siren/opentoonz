# NextToonz Phase 2 发布说明（草稿）

Phase 2（核心去 Qt，`doc/nexttoonz_core_noqt.md`）还在本地分支 `wip/phase2-noqt` 上，没有合并、没有推送。这份说明随步骤补充，发布时再定稿。用户看得到的变化只有下面几条；其余每一步都验证过默认路径不变（渲染、存档、界面文字逐字节相同）。

## 修好的问题

- **tconverter 在 macOS 和 Windows 上能用了**（第 6a 步）。它在这两个平台上从来不建 Qt 应用对象，以前因此把所有路径都当作不存在，什么都转不了。
- **多线程渲染里笔画 id 可能重复**（第 8d 步，已知问题第 33 条）。几个线程同时读关卡时，两条笔画可能拿到同一个 id。现在不会了。过去用 `-nthreads` 大于 1 渲染时偶发的怪现象，可能与它有关。

## 行为的变化

- **便携模式多看一处**（第 6c 步）：tconverter 在 macOS 和 Windows 上也检查可执行文件旁边的 `portablestuff`。
- **在应用对象建立之前，文件状态报告真实情况**（第 6a 步）。实测只有 tconverter 在那之前问过。
